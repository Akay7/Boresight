Flash the ESP32-CAM

Looking for a firmware to flash…

This browser cannot flash. Flashing over the USB-serial adapter needs Web Serial: desktop Chrome or Edge, with the page opened over HTTPS (the project's published site) or on localhost (mkdocs serve in a checkout).

The image files are below for flashing from the command line instead.

No firmware here yet. In a checkout, build it with

firmware/boresight-cam/tools/idf.sh device build

and restart mkdocs serve. Or flash the latest released image from the project's flashing page.

  1. Wire the board to the USB-serial adapter as in the README, and plug the adapter in.
  2. Fit the jumper from IO0 to the GND beside it, then press RST. The adapter cannot put an ESP32-CAM into download mode by itself; this does.
  3. Press Connect, pick the adapter's serial port (a CP210x, CH340 or similar), then choose to install the firmware.
  4. When asked whether to erase the device first, leave it unticked to keep the settings stored on the board. Erasing also erases them, and the board then starts in setup mode.
  5. When it is done, remove the jumper and press RST.

If it reports that the board did not answer, or failed to initialise: the board is probably not in download mode. Check the jumper is on IO0 and GND, press RST, and try again. If it still does not answer, swap the TX and RX wires.
